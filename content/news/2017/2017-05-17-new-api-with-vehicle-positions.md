A new push API with information about real-time positions of public transport vehicles is now available on Trafiklab.

![](/media/2017/05/2017-05-17-nytt-api-med-fordonspositioner-1.gif)

At present, the API delivers information for all trains operated by Värmlandstrafik and Norrtåg. The information comes from Oxyfi's onboard Internet system. Work is also under way to include trains from other train operators. You can get documentation and API keys on Trafiklab.

[Here you can read more about the API and get your API key.](https://www.trafiklab.se/api/oxyfi-realtidspostionering)
