**The SL Reseplanerare 2 API will be switched over to a new system version on Thursday 15 June. The work will take place between 10:00 and 14:00.**

**The work being carried out should not cause any downtime. The switchover does not involve any changes to the public interface.**

The new system version contains fixes for previous problems with

- departures incorrectly shown as cancelled
- disruption information in the journey planner
- odd journey suggestions for unsharp searches

If you notice anything odd or any problems in connection with this work, please get in touch [here](https://kundo.se/org/trafiklabse/).
