**During yesterday's meetup at Taxi Stockholm, Karin Werner from Taxi Stockholm presented a new API that enables integration of taxi booking in third-party services. In addition, Oxyfi presented a new API for real-time information on train positions, which will soon be available through Trafiklab. Lars Löfquist from Samtrafiken live-hacked a way to reduce the number of calls to the real-time APIs on Trafiklab.**

![](/media/2017/04/2017-04-26-trafiklab-meetup-taxistockholm-25-april-2017-2.jpg)

During the meetup, Andrey and Johan, the people behind Sthlm Traveling, launched the new service Tapto. Sign up for the beta test here: [usetapto.com/beta](http://usetapto.com/beta)

Trafikverket presented a number of new datasets that are available or coming soon, including camera images from the road network and information about road ferries. Trafikförvaltningen (SL) presented upcoming quality improvement work and the planned transition to a new version of the journey planner.

In May, Startup Weekend will run an event in Stockholm focused on Travel. More information and registration at [stockholm.up.co](http://stockholm.up.co/) (discount code **SW4TRAFIKLAB**). This autumn the rolling hack Trainhack will take place, and more information is available at [trainhack.se](http://www.trainhack.se).

Going forward, a number of deep dives will be held within a few selected areas. On these occasions there will be an opportunity to go deeper into questions and ideas related to specific issues. The areas that will be covered initially are APIs for real-time information, Open sales and Crowdsourced disruption information.
