Today, 5 June, the documentation for SL's four new APIs was rolled out on Trafiklab.

* [SL Realtidsinformation 3](http://www.trafiklab.se/api/sl-realtidsinformation-3)
* [SL Trafikläge 2](http://www.trafiklab.se/api/sl-trafiklaget-2)
* [SL Störningsinformation 2](http://www.trafiklab.se/api/sl-storningsinformation-2)
* [SL Platsuppslag](http://www.trafiklab.se/api/sl-platsuppslag)

The documentation contains all the information needed to get started with SL's new production APIs. For questions, please refer to our support forum [kundo](https://kundo.se/org/trafiklabse/).

You will see the following icon in the API list:

![](/media/2014/06/2014-06-05-sls-nya-apier-i-produktion-1.png)

What does this icon mean? This icon indicates an API that still works but will be taken out of production by the provider in the near future. In other words, you should no longer create new applications based on these APIs.
