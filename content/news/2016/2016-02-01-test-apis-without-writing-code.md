With the consoles for the ResRobot APIs, you can test-run the APIs without writing any code at all. You enter search parameters just like in a journey planner and see the API response as well as the code for the API request.

Try it yourself [here](https://www.trafiklab.se/api/resrobot-reseplanerare/konsol).
