---
title: "Real-time information in SL's journey planner API"
date: 2015-10-28

---

We've mentioned it before - but now real-time information is finally being released in SL's API for journey planning.

If you're curious about how the API can be used, you can try out what has now been implemented on sl.se. The functionality is available in SL's API - Reseplanerare 2, and you'll of course find the documentation here on Trafiklab.

You don't need a new API key to access the new methods, and other existing methods are unchanged.

[https://www.trafiklab.se/api/sl-reseplanerare-2](https://www.trafiklab.se/api/sl-reseplanerare-2)
