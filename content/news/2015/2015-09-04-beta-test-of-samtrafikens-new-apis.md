---
title: "Beta test of Samtrafiken's new APIs"
date: 2015-09-04

---

**For some time now, Samtrafiken has been working on replacing the back-end platform for the APIs towards Trafiklab. The new platform will enable new functionality and better operational stability. To end up with the best possible final product, we would already now like to invite you as a Trafiklab user to test the new APIs.**

The APIs now available for testing are:

- Resrobot - Sök Resa (new name Resrobot – Reseplanerare with the helper methods Platsuppslag and Närliggande Hållplatser)
- Resrobot - Stolptidstabeller (new name Resrobot – Stolptidstabeller 2)

The project's ambition is to move these APIs into production on 1 October 2015. During October a new GTFS extract will also be launched on Trafiklab. The old APIs will remain available in parallel with the new ones until 19 December 2015. To end up with the best possible APIs, we are incredibly grateful for feedback from those of you testing the new APIs. Send feedback to [info@samtrafiken.se](mailto:info@samtrafiken.se) or through our forum under “Contact us” on trafiklab.se.

The documentation for the new APIs is already available on Trafiklab.se.

Don't hesitate to get in touch if you have any questions or thoughts!
