---
title: "Updates to Trafiklab's APIs this spring"
date: 2015-03-18

---

Hi everyone!

The following changes will be made to Trafiklab's APIs during spring 2015.

* SL is introducing a new API for stop and line information requests (version 2)
* Samtrafiken's Sök Resa and Stolptids APIs get new, refreshed documentation in Swedish.
* Improvements are being made to improve the user experience on Trafiklab. The changes focus mainly on use from mobile devices.
* Samtrafiken is publishing a new API for mapping between the transport operators' stop IDs and the national stop IDs. Initially the mapping is added as a method in the GTFS API (uses the same key), but it may get its own entry point in the future.
* Old versions of GTFS files are being published on Bitbucket. Here we at Trafiklab will try out how it works to deliver data without a key procedure. Feedback is welcome!
* Trafikverket is beta testing an extension of its open API to also include information about road traffic (in addition to train data). Read more about it in an earlier blog post and in the documentation of the API Trafikverket Öppet API.
